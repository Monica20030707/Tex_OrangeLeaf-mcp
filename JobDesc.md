Job Title: DevOps Intern (6-Week Training Program)
Location: Redmond, WA 
Duration: 6 Weeks Training Program
Employment Type: Internship / Training Program
About the Program
We are offering a comprehensive 6-week DevOps Internship Training Program designed for aspiring IT professionals who want to gain hands-on experience in DevOps, Cloud Computing (AWS), Automation, CI/CD, and Infrastructure Management. Participants will receive practical training, work on real-world projects, and develop industry-relevant skills.
Responsibilities
Learn and implement DevOps methodologies and best practices. 
Assist in building and managing CI/CD pipelines. 
Work with source code management tools such as Git and GitHub. 
Deploy and manage cloud infrastructure on AWS. 
Create and manage containerized applications using Docker. 
Learn Kubernetes for container orchestration. 
Implement Infrastructure as Code (IaC) using Terraform. 
Monitor system performance, logs, and application health. 
Collaborate with mentors and team members on technical projects. 
Participate in workshops, technical sessions, and project reviews. 
Required Qualifications
Bachelor's or Master's degree in Computer Science, Information Technology, Engineering, or a related field (completed or pursuing). 
Basic understanding of Linux operating systems. 
Knowledge of networking fundamentals. 
Basic programming or scripting knowledge (Python, Shell Scripting, or Bash). 
Understanding of Software Development Life Cycle (SDLC). 
Strong analytical and problem-solving skills. 
Passion for learning DevOps and Cloud technologies.
